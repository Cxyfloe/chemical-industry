# Chemical Industry（化学工业）

> [English](README.en.md) | [中文](README.md)

一个给 [Create（机械动力）](https://github.com/Creators-of-Create/Create) 做的化学工程附属模组，支持 MC 1.21.1 / NeoForge。

把现代化学工业搬进 Minecraft：从捡到第一块硫磺矿开始，到建立起自己的化工厂，中间要经历烧矿、造酸、电解、炼金属、分离空气这一整套流程。

## 这个模组有什么

**一条完整的化工路线。** 矿石不只是用来烧成锭——硫磺矿炼成硫酸，岩盐电解出氯气和烧碱，铝土经过酸碱处理变成铝，黄铁矿一炉烧出氧化铁……每种原料都有自己的去处，玩下去会发现整个流程环环相扣。

**四台主力机器：**

- **沸腾炉**——大锅炉，烧结矿石、造硫酸、炼钢都在这里
- **电解槽**——3×N 的多方块电解池，通电后分解出金属和气体
- **空气压缩机**——把空气压成压缩空气
- **冷凝管**——接上压缩空气和鼓风机，能真的把水冻成冰

**二十多种流体。** 硫酸、盐酸、硝酸、各种盐溶液、液态水银，还有氯气、氢气、氧气这些气体。气体要用储气罐装，小心管道泄漏。

**空气分离。** 压缩空气送进分馏塔（来自《机械动力：柴油动力》），分离出氧气、氮气和稀有气体——稀有气体是后期的重要材料。

**一点小小的"安全教育"。** 堵管会爆炸，酸液混水会爆炸，电解氢氟酸直接送你去重生点。化学工业嘛，总要付出点代价。

**温度计。** 玻璃罐装上水银就是温度计，指针会跟着周围温度转：站岩浆边上是红色，跳进雪地里是蓝色。

**Ponder 教程。** 每台机器都内置动画教程，游戏里拿着方块按 W 键就能看。

## 玩法路线（给新玩家）

1. 挖到硫磺矿，在沸腾炉里烧出硫酸——这是整个流程的起点
2. 用硫酸和盐做出盐酸、硝酸
3. 搭电解槽，电解出金属和气体
4. 攒够金属，升级合金工具和盔甲
5. 建空气压缩机 + 分馏塔，分离空气
6. 之后自由发挥：炼铝、制氟、提纯贵金属……

## 安装

1. 安装 NeoForge 21.1.80（对应 MC 1.21.1）
2. 装好上面三个依赖模组
3. 把下载的 jar 放进 `.minecraft/mods/`

## 关于开发

这个模组是用 **vibe coding** 的方式开发的：我负责想玩法、设计流程、在游戏里搭场景测试，AI 负责写代码、查 API、做贴图和 Ponder 教程。代码可能算不上"标准"，但每个机制都在游戏里实际验证过。
